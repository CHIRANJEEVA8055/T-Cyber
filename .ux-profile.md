# UX profile: T-CYBER

Product: operational case workspace for authorised police officers. Calm, restrained, readable. The product brief
(T_CYBER_Claude_Code_Master_Prompt.md) and the user's Figma-grade optical rules take precedence over skill defaults.

## Accessibility target
- WCAG 2.2 AA. Visible focus (2px ring, 2px offset, `--color-focus`). Status never conveyed by colour alone.
- Hit targets: 40px controls on fine pointers (brief: 40–44px); 44px on coarse pointers (`pointer-coarse:`).

## Type (brief overrides skill defaults)
- IBM Plex Sans (bundled locally), weights 400 / 500 / 600 only. System monospace only for hashes and raw document lines.
- Body and table cells 14px / 1.5. Labels 12–13px. Meta 12px (timestamps, helper text only). Section headings 16–18px.
  Page titles 24px. Headings use tracking-tight and leading-tight. Tabular numerals everywhere (set on body).

## Colour and depth
- Canvas #F5F6F8 (L0), surface #FFFFFF (L1), muted surface #F8F9FA. Ink #18181B / #52525B / #6B6B74.
- One action colour: navy #1F4B8F (hover #193D75, tint #EDF2FA). Semantic tones: success, warning, danger, neutral.
- Hairline borders black/7% on panels; inputs black/18% so fields stay identifiable.
- Raised surfaces: `0 1px 2px rgba(0,0,0,.05), 0 8px 16px -4px rgba(0,0,0,.1)` plus inset top highlight (user rule).
- Blur is allowed ONLY on the sticky top bar, the floating graph toolbar and modal scrims (user rule), with ≥85%
  opaque backgrounds and an opaque fallback. Dialog and drawer panels are always opaque.

## Layout
- Breakpoints: narrow < 768, medium 768–1279, wide ≥ 1280. Sidebar 240px (collapsible to 64px), top bar 56px.
- Main content max width 1440px (graphs and wide tables may use full width). Content padding 24px / 32px.
- Radii: controls 6px, panels 10px, chips 4px; nested radius = outer − padding.

## Voice
- Plain operational language, sentence case, verb-first actions. No OK / Submit / Proceed.
- Errors: blameless, ≤2 sentences, with a recovery step. Uncertainty is stated, never hidden ("Unknown", "Unverified").

## Banned
- Gradients, neon, glows, glass panels, decorative illustrations, AI sparkles, oversized statistics, giant greetings,
  all-caps labels, middle-dot metadata strings, arrow-suffixed buttons, "case solved" percentages.
